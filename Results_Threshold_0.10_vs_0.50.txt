The Journey: What Went Wrong with Cosine
Step 1: Original Cosine Model (Your First Attempt)
Table
Problem	Evidence
Representation collapse	All similarities clustered at ~0.99
No discrimination	Model matched 100% of targets with AIS candidates
False confidence	Even "worst" matches scored 0.76+
Why it happened: L2 normalization + cosine loss allows the model to "cheat" by making all embeddings point in nearly the same direction. The loss is minimized because the angle between vectors is small, but the model never learns to distinguish vessels.
Step 2: We Tried to Fix It
Table
Attempt	Result
Lower threshold (0.10 → 0.50)	Still matched everything
Higher threshold (0.95)	Rejected everything — not useful
More data (multi-dataset)	Helped slightly, but collapse persisted
The root cause: Random negative sampling. Negatives were trivially easy (vessels 50km apart), so the model never learned fine-grained discrimination.
Why Euclidean Loss?
Table
Aspect	Cosine	Euclidean
What it measures	Angle only	Magnitude + direction
Collapse risk	High — can align all vectors	Lower — must separate in space
Interpretability	Bounded (-1 to 1)	Raw distance (0 to ∞)
Training stability	Collapsed to ~0.99	Stable at ~0.17 loss
Key insight: With Euclidean distance, the model can't just make all vectors point the same way — it actually has to push negatives far apart in the embedding space. The margin (1.0) creates a "buffer zone" that forces meaningful separation.
Why Hard Negative Mining?
Random Negatives (Before)
plain
Radar target at Location A, 15:00
    └── Negative: AIS at Location Z, 20:00 (100 km away)
    
Model learns: "Far apart = different" ← Trivially easy
Hard Negatives (After)
plain
Radar target at Location A, 15:00
    ├── Positive: AIS Vessel 1 at Location A, 15:00 (50m away) ← Same vessel
    └── Negative: AIS Vessel 2 at Location A, 15:00 (180m away) ← Different vessel!
    
Model must learn: "Same area, same time, but different = different" ← Actually hard
Why this matters: Hard negatives force the model to learn vessel-specific features (speed, course, signal characteristics) rather than just "same location = same vessel."
The Combined Effect
Table
Component	Purpose
Euclidean loss	Prevents collapse, enforces spatial separation
Hard negatives	Provides challenging examples for real learning
Margin = 1.0	Creates clear boundary between match and non-match
No L2 norm	Magnitude carries information
